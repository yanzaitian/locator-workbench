# 定位工作台

## 云端版与本地版（2026-10-26）

本项目现在包含两套入口：

- **云端工作台**：`site/` 静态页面由 GitHub Pages 托管，GitHub Actions 调用小米账号接口并发布加密设备状态。此入口不依赖个人电脑开机；真实位置能否更新仍取决于小米凭据、设备状态和 Actions 运行结果。
- **本地工作台**：`server.py` 提供完整本地管理、邮件导入和 DeepSeek 月报，个人电脑关机后本地入口不可访问。云端现已提供计划表单、加密历史、月报预览及只读邮件导入模块；实际邮件收取尚未配置。

云端页面的密码用于浏览器内解密设备状态。云端每设备计划可通过「计划管理」表单加密提交，发布回执确认后生效。首次管理授权需要限定仓库的 GitHub Actions 写入权限；可选择加密记住授权。`cloud/plans.enc.json` 优先于初始 `XM_PLANS` Secret。云端调度配置为每 10 分钟发起一次，GitHub 可能延迟执行，不能保证准确间隔。

部署和验收以 [GitHub 部署指令](docs/GitHub部署指令.md) 与 [交接说明](docs/交接说明.md) 为准。下面的手机采集、局域网访问和月报说明主要针对本地版。


个人使用的手机定位控制台：**计划在电脑上设置，执行在手机上，汇报在电脑上生成并永久保存。**

- 工作区：C:\Users\17304\定位工作台
- 数据目录：%LOCALAPPDATA%\LocatorWorkbench（数据库、汇报、归档）
- 默认端口：8765

## 1. 它怎么工作（先看这张图）

    手机（备用机 K70 Pro，Termux）                      电脑（定位工作台，运行中）
    ┌──────────────────────────────┐                  ┌───────────────────────────┐
    │ 每 60 秒：                    │  同 Wi-Fi 时      │ Web 界面（手机/电脑都能开）│
    │  1. 拉取最新「定位计划」       │ ───────────────▶ │  · 计划设置               │
    │  2. 按计划判断现在该不该定位    │                  │  · 汇报生成（DeepSeek）    │
    │  3. 定位 → 写本地缓冲          │ ◀─────────────── │  · 数据与设备状态          │
    │  4. 连得上就上传，连不上先存着  │   上传位置点      │  · 每月自动汇报            │
    └──────────────────────────────┘                  └───────────────────────────┘
               │ 电脑关机时
               ▼
      用上次缓存的计划继续采集，数据存在手机本地；电脑开机后自动补传。

**关键点**：电脑不用一直开机也能按计划定位，因为计划缓存在手机上；但**电脑关机时手机打不开网页**（网页跑在电脑上）。

## 2. 电脑端（一次性）

1. 双击 run.bat（或在目录里执行 python server.py）。
2. 浏览器打开 http://127.0.0.1:8765
3. 首次启动会在 Windows 防火墙弹窗时选择「允许（专用网络）」，否则手机连不上。
4. 打开「设置」：
   - 填 DeepSeek API Key（不填也能用本地模板生成汇报）
   - 需要邮件兜底再填 QQ 邮箱 IMAP + 授权码
5. 打开「计划」，设置每天几点到几点、每隔多久定位；需要单独的星期（比如周一）勾“单独”。

默认已设置**开机自启**（隐藏窗口运行，登录 Windows 后自动启动并补生成月报）。

- 想关闭自启：右键用 PowerShell 运行 autostart_off.ps1（或删除「启动」文件夹里的“定位工作台”快捷方式）。
- 想手动调试：双击 run.bat（会显示日志窗口）。
- 想停止后台服务：双击 stop.bat。

---

## 3. 手机端（备用机，一次性）

需要：Termux、Termux:API、Termux:Boot 三个 App（F-Droid 下载）。

1. 把 phone/ 目录拷到手机。
2. Termux 里：sh install.sh
3. 电脑网页「概览」里复制 **地址** 和 **令牌**。
4. 编辑手机配置：nano ~/.locator-workbench/config.json
   - workbench_url 填电脑地址（如 http://192.168.1.10:8765）
   - token 填网页上的令牌
   - device_id / device_name 随便起名
5. 测试：python ~/.locator-workbench/collector.py --once
6. 常驻：python ~/.locator-workbench/collector.py
7. 系统设置给 Termux：自启动、后台无限制、省电无限制。

配置好后，手机每次连上电脑（同一 Wi-Fi、电脑开着）都会拉取最新计划；计划改了不用动手机。

## 4. 计划规则

- 每天时段：开始/结束时间，支持跨天（22:00–06:00）。
- 间隔：窗口内每 N 分钟定位一次（最小 5 分钟）。
- 每周：默认计划 + 7 个星期可单独覆盖（比如周一 07:30 开始、每 20 分钟）。
- 节假日：内置 2025–2026 国务院法定节假日与调休上班日，可自动跳过；调休上班日按单独的计划执行。
- 节假日日历可在页面上直接编辑（每行一个日期），2027 年公布后补进去即可。

手机端用**同一套规则**判断；所以电脑关机时也按计划走。

## 5. 汇报

- 「汇报」页选月份，点「用 DeepSeek 生成」，生成后永久保存（同一月份多次生成会保留多版本）。
- **每月 1 号电脑开机后，自动生成上个月的汇报**；如果 1 号没开机，下次开机自动补上。
- 没填 DeepSeek Key 时用本地模板生成，不会失败。
- 可导出 Markdown。

## 6. 手机查看网页

手机与电脑连同一个 Wi-Fi、电脑开着时，浏览器打开「概览」页显示的地址即可（如 http://192.168.1.10:8765）。
建议在手机浏览器里「添加到主屏幕」，像 App 一样打开。

## 7. 常见问题

**手机显示连不上电脑？** 检查：同一 Wi-Fi；电脑防火墙允许专用网络；地址端口对；电脑上的服务窗口没关。

**电脑关机时手机还按计划定位吗？** 会，使用上次同步的计划。数据先存手机本地，电脑开机后自动上传。

**网页上计划改了，手机没生效？** 手机下次连上电脑（同一 Wi-Fi、电脑开着）才会同步；着急的话在手机上打开一次采集器（或等它每分钟重试）。

**每月 1 号没自动生成？** 电脑 1 号没开机时会等到下次开机；也可以手动点生成。

**数据在哪？** %LOCALAPPDATA%\LocatorWorkbench\workbench.db 与 reports\；备份复制整个目录即可。

**换端口/换电脑？** 改 config.json 的 server.port；手机端地址同步改。

## 8. 限制与安全

1. 手机没网/关机时无法定位，任何软件都一样；小米「查找设备」仍是丢机时的主手段。
2. 本地手机采集可由手机自己上报；云端小米采集会访问本人账号的非官方 Find/v3 接口，可能遇到凭据过期、额外验证、接口变化或限流，无法承诺不触发风控。
3. 网页服务监听在局域网，请只在可信 Wi-Fi 使用；手机接口需要令牌。
4. 电脑关机时本地服务入口不可访问；GitHub Pages 云端入口不依赖电脑开机，仍需完成云端部署和真实采集验收。
5. 只用于定位你自己的设备。
